# 圖解手冊的截圖清單

安裝時照這份清單截圖，之後會標註成圖文手冊。

## 怎麼截

- **Mac**：`Cmd + Shift + 4` 然後按一下**空白鍵**，游標變成相機，點視窗就只截那個視窗，不會把桌面雜物帶進去
- **瀏覽器視窗固定一個寬度**（建議 1440），每張圖大小一致，手冊才不會忽大忽小
- **不用自己遮金鑰**，標註工具會遮。但原圖本身很敏感，**不要貼到任何公開的地方**
- 檔名照下面的編號，例如 `01-line-建立provider.png`
- 全部放進 `docs/raw/`（這個資料夾已經排除版控，不會被 commit）

## 清單

### 步驟 1：LINE 機器人

| 編號 | 要截什麼 | 重點圈在哪 |
|---|---|---|
| 01 | LINE Developers Console 首頁 | 「Create a new provider」按鈕 |
| 02 | 選擇頻道類型的畫面 | 「Messaging API」那個方塊 |
| 03 | Basic settings 分頁 | Channel secret 的位置 |
| 04 | Messaging API 分頁**最底部** | Channel access token 的 Issue 按鈕 |
| 05 | Auto-reply messages 設定頁 | 關閉自動回覆的開關 |

### 步驟 2：Firebase

| 編號 | 要截什麼 | 重點圈在哪 |
|---|---|---|
| 06 | Firebase Console 建立專案 | 建立按鈕 |
| 07 | Firestore 建立資料庫的**地區選單展開中** | `asia-east1` 那一列 |
| 08 | Storage 建立時的地區選擇 | `asia-east1` |
| 09 | 專案設定 → 服務帳戶 | 「產生新的私密金鑰」按鈕 |
| 10 | Storage 頁面最上方 | bucket 名稱那一行 |

> 07 跟 08 最重要。地區選錯只能砍掉重建，手冊要讓人一眼看到該選哪個。

| 編號 | 要截什麼 | 重點圈在哪 |
|---|---|---|

## 收完之後

把 `docs/raw/` 整包給我，我會：

1. 裁掉無關的瀏覽器分頁與桌面
2. 遮掉金鑰、token、服務帳戶信箱
3. 圈出該點的地方並編號
4. 編排成 `docs/圖解安裝手冊.md`

標註工具是 vault 根目錄的 `tools/annotate.py`。
