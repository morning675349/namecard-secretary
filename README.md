# 名片特助

**給 B2B 業務用的 LINE 機器人**，把收來的名片變成跟得完的名單。

展覽收四十張、商會一早收八張、客戶拜訪一次兩三張。問題從來不是收不到名片，是收回來之後沒有人整理，也沒有人提醒你該聯絡誰。

> 由 **多比智DoBBiz** 開源釋出。
> 多比智DoBBiz 是 AI 驅動的 B2B 智慧媒合平台，串接企業採購、供應鏈、產業協會、學界資源。

拍一張名片傳給它，十幾秒後你會收到一張卡片：名片原圖、辨識結果、評分、分類、建議跟進日期。資料同時存進你自己的資料庫，之後可以搜尋、記筆記、匯出名單。

**所有資料都在你自己的 Firebase 專案裡，沒有第三方服務碰得到。**

---

## 它解決什麼問題

名片收回來堆在抽屜，三個月後想找某個人，只記得「那個做自動化的」，但名字和公司都想不起來。

這個機器人讓你：

- **當場建檔**，不用事後花一個晚上輸入
- **用講的找人**：「找一下做精密車床那家」
- **不會忘記跟進**：每天早上 8 點推播今天該聯絡誰
- **重複的人自動併起來**：同一個人在不同場合又給你一張名片，不會變成兩筆
- **活動後一次收割**：展覽收了四十張，收攤時自動給你分級名單與跟進順序

## 主要功能

| 功能 | 說明 |
|---|---|
| 名片辨識 | 拍照自動抓姓名、公司、職稱、電話、Email、地址、服務項目 |
| 台灣人名優化 | 針對罕見字逐偏旁確認（瀞不是靜、婕不是媛），這是台灣名片最常出錯的地方 |
| 誠實回報不確定 | AI 沒把握的欄位會標出來，不會默默給你錯的資料 |
| CRM 評分 | 依你的生意邏輯打 1 到 10 分、自動分類、給跟進建議 |
| 認識場合自動判定 | 從你的 Google 日曆推測「在哪認識的」，展覽或例會都抓得到 |
| 展場模式 | 連續掃幾十張時回覆變精簡，收攤自動出戰果報告 |
| 重複名片去重 | 姓名與電話都相同就自動併成一筆，手機撞號但姓名不同會問你是不是同一人 |
| 批次起草跟進 | 一次產五則跟進訊息，會引用你記的現場筆記 |
| 名單匯出 | CSV 下載連結，電子報系統可直接匯入 |
| 每日提醒 | 早上 8 點推播今天該跟進誰，沒事就不吵你 |
| 網頁後台 | 列表、編輯、篩選、匯出 Excel |
| 錯誤看得見 | 失敗原因寫進資料庫，後台讀得到，不必翻雲端 log 猜問題出在哪 |

## 開始使用

### 你需要準備

| 服務 | 用途 | 費用 |
|---|---|---|
| LINE Messaging API | 機器人本體 | 免費 |
| Firebase | 資料庫與圖片儲存 | 免費額度足夠個人使用 |
| OpenAI | 名片辨識與對話 | **要付費**，單人使用約每月 5 到 15 美元 |
| Google Cloud | 日曆授權 | 免費 |
| Vercel | 部署 | Hobby 方案免費 |

除了 OpenAI 要儲值，其他都在免費額度內。

### 三種安裝方式，挑一種

**① 讓 AI 帶你做（最省事）**

把整個資料夾丟給 Claude Code、Codex 或任何 AI 編碼助理，跟它說：

```
幫我把這個裝起來，我是做 ___ 的
```

它會先問你幾個問題把設定改成你的生意邏輯，然後一步一步帶你部署，
每一步都會實際驗證，不會讓你以為做好了其實漏一步。

指引在 [AGENTS.md](AGENTS.md)，AI 自己會讀。
**你的金鑰自己填進 `.env.local`，不用貼給 AI**，它只跑健檢腳本看結果。

**② 看圖照做**

[docs/圖解安裝手冊.md](docs/圖解安裝手冊.md)，每個要點的地方都圈起來了。

**③ 看文字步驟**

[SETUP.md](SETUP.md)，技術細節與疑難排解都在這份。

三種都是大約一小時。

### 裝到一半卡住

```bash
node scripts/setup-doctor.mjs --live
```

會檢查 13 項設定的格式、實際呼叫 LINE 與 OpenAI 確認服務活著，
哪裡錯就告訴你怎麼修。不會印出你的金鑰。

如果你不想自己讀文件，**把整個資料夾丟給 Claude Code 或 Codex，跟它說「幫我設定成我自己的版本」**，它會讀 [AGENTS.md](AGENTS.md) 然後訪談你、改好設定、帶你部署。

### 客製成你的生意

只要改 **`config/profile.ts`** 一個檔案。

裡面是你的職業、目標客戶、名片分類、評分標準、常去的場合。改完之後，AI 就會用你的角度判斷每一張名片值不值得跟進。

其他程式碼都不用動。

## 技術

Next.js 16（App Router）、Firebase Admin SDK、OpenAI、LINE Messaging API，部署於 Vercel。

```bash
npm install
npm test          # 純邏輯模組的單元測試
npm run dev
```

測試只涵蓋不碰外部服務的模組（場合判定、戰果排序、CSV、卡片組裝、批次處理）。

碰 OCR、LINE、Firebase 的部分靠型別與線上驗證。

## 關於多比智DoBBiz

這個工具由 **多比智DoBBiz** 開源釋出。

### 為什麼做這個工具

我們在展覽、媒合會、商會場合看過太多次同一個畫面：工廠老闆收了一疊名片回去，然後就放著。

名片堆著不是問題，**實力沒被看見**才是。

這也是多比智DoBBiz 在做的事，只是規模更大。

**工廠的實力，別只讓熟人知道。**

### 平台在做什麼

三件事：

- **精準媒合**：串接採購端與供應商端的實際需求
- **協會交流與會員曝光**：協會上傳會員名單，供應商頁面顯示所屬協會，讓採購知道可以去問誰
- **串接學界資源**：學校端可授權的專利技術，讓工廠有機會做轉型升級

一般的 B2B 平台只給你訂單，公會只給你人脈，學校產學中心只給你技術。

多比智DoBBiz 想做的是把採購、供應商、產業協會、學界四邊接在一起。

協會與學校還在一所一所接進來，路才剛開始，但方向很明確。
